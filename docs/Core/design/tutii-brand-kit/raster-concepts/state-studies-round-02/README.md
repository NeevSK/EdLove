# State studies — round 02

Six individual concept illustrations to complement the first-use empty sample:

- `state-search-empty.png` — no search/filter matches; curious rather than disappointed.
- `state-offline-available.png` — offline while the user still has local content to work with.
- `state-work-queued.png` — a completed action is safely waiting to sync.
- `state-long-wait.png` — reassurance for unusually long waits and service maintenance.
- `state-recoverable-error.png` — a calm retry path after an action fails.
- `state-not-found.png` — an item may have moved; guide the user toward a useful route back.

All six use the firefly Tutii identity as reference. These are concept art, not production-approved assets or app integrations. See the parent `state-coverage.md` for the complete state-to-art mapping, including states that should stay text-first.
