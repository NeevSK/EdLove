# Scene studies — round 03

Fourteen individually generated context-scene concepts. These are review art only and are not approved for production use.

- Student reflection and return after a break
- Teacher attendance, feedback, classroom transition, and end-of-day wrap
- Principal school-plan review and shared decision making
- Guardian reading a school notice and family progress recognition
- Librarian recommendation
- Learner collaboration
- Community tree planting and open day

Tutii is placed within the people and activity in each scene. Check gaze, consistency, cultural details, palette, and crop behavior before selecting any for the product.
