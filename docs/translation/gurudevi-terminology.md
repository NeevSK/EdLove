# Gurudevi Translation Terminology

This is the review source for Gurudevi terminology used by the web and mobile
applications. Only entries marked `approved` should be published through an
external translation glossary. Entries marked `review` are existing product
wording that still needs native-language confirmation.

The name is governed by the Gurudevi philosophy document:
`apps/gurudevi-mobile/docs/Core/educational-ecology-philosophy.md`.
It requires the short-vowel forms `ගුරුදෙවි` and `குருதெவி`, meaning divine
teacher rather than goddess.

The machine-readable catalog is in
`packages/core/src/logic/i18n/gurudevi-terminology.ts`.

Google Cloud glossary-ready exports are kept beside this document:

- `gurudevi-glossary-en-si.tsv`
- `gurudevi-glossary-en-ta.tsv`

They contain only the approved product name and public taglines. Credentials,
project IDs, and uploads are intentionally not stored in the repository.
