# Imported Exploration Corpus

This directory is an evidence archive for the Gurudevi-first Edlove exploration
integration program. The findings in the imported files are preserved as
historical source material and are not rewritten here.

Use these documents together with:

- [Integration plan](../current_progress/2026-08-10-gurudevi-edlove-exploration-integration-plan.md)
- [Current implementation comparison](../architecture/2026-08-10-gurudevi-edlove-exploration-vs-current-implementation.md)
- [Documentation SOP](../docs-sop.md)

The comparison document separates imported claims from fresh repository scans,
schema evidence, migration state, and test results. Database-review batches
01–06 remain prior work and are linked from that comparison rather than copied
into this archive.

## Corpus inventory

The numbered files cover biomimicry, data architecture, UI/UX, transport,
storage, query patterns, media, Self, Classroom, Community, governance, AI,
Profile, notifications, Workspace, Library, temporal architecture, derived
history, and GlobalHeader. `SKILL.md` remains the corpus-specific reading guide.
