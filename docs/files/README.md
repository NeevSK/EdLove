# Imported Exploration Corpus

This directory is an evidence archive for the Gurudevi-first Edlove exploration integration program. The findings in the imported files are preserved as historical source material.

To make these documents easier to navigate, they are organized into two tiers:
1. **`fundamental/`** — Main, reusable documents that can be applied to any app or package in the platform (e.g. biomimicry, network transport, visual design philosophy, query patterns).
2. **`specialized/`** — Specialized documents targeting specific domain audits, tabs, or screens for Edlove or Gurudevi-mobile (e.g. Classroom audit, Self/Library tab, DerivedHistoryView).
