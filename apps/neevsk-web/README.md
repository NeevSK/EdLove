# NeevSk Web

> "Everything I want to show to the world."

The personal digital archive, portfolio, and "Hall of Flame" for NeevSk. A space for the "Existential Cyberneticist, INFJ 4w5, Epistemic Architect, Bohemian Philosopher."

## 🧠 Core Concept

This is the personal digital space of the creator, serving as the "Soul" behind the machine (EdLove). It is intimate, philosophical, raw, yet refined.

## 🌟 Key Sections

- **Home**: Aligning with the creator's persona.
- **CV**: Professional journey and skills.
- **Projects & Portfolio**: Showcasing work and creations.
- **Hall of Flame**: A tribute to those who inspired, loved, and taught mastery. A sacred space of memory and honor.
    - *The First Light*
    - *Chamber of Love*
    - *Chamber of Tribute*
    - *Chamber of Mastery*
    - *Chamber of Inspiration & Respect*
    - *Chamber of Support*
- **Life Journey**: A timeline or narrative of personal evolution.
- **Digital Archive**: A collection of thoughts, essays, and artifacts.
- **Contact**: Ways to connect.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Deployment**: Vercel (Platform standard)

## 🚀 Getting Started

1.  **Install dependencies**:
    ```bash
    pnpm install
    ```

2.  **Run development server**:
    ```bash
    pnpm dev
    ```

3.  **Build for production**:
    ```bash
    pnpm build
    ```
