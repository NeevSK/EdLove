# Gurudevi Design Framework
## Mobile App for Sri Lankan Teachers

---

## 🪷 Core Philosophy

**Gurudevi** (ගුරු දෙවි) — "Divine Teacher"

The lotus (nelum mala) is our guiding metaphor:
- **Rooted in mud** — acknowledging the difficult conditions teachers work in
- **Rising through water** — the journey of growth and resilience  
- **Hydrophobic surface** — protecting purity and dignity while navigating challenges
- **Blooming above** — achieving enlightenment and sharing knowledge

---

## 🎭 Barthes: Studium vs Punctum

### Studium
The **cultural, informational layer** — what we generally understand and expect.

In Gurudevi:
- Lesson plans, resources, schedules
- Forums, profiles, library content
- The functional infrastructure of teaching

### Punctum
The **piercing detail** — what wounds, bruises, moves us emotionally.

In Gurudevi:
- A lotus petal assistant appearing at the moment of exhaustion
- A firefly guiding you when lost
- The sound of temple bells when a mentor responds
- A traditional oil lamp lighting for your breakthrough
- Batik patterns that ripple like living water

**Design principle**: Studium provides structure, punctum provides soul.

## 🏗️ App Architecture — Five Pillars

```
Bottom Navigation (WhatsApp-style 5 tabs):

🧘 Self          🏫 Workspace     🌸 Community     📚 Library       👤 Profile
(Sanctuary)     (Role-Specific)  (Connection)     (Knowledge)     (Identity)
```

### 1. 🧘 Self (Sanctuary)
**Essence**: Your inner refuge  
**Feeling**: Quiet dawn at a temple, mist on water  
**Purpose**: Personal wellbeing, reflection, journaling  
**Interaction**: Soft, responsive, intimate  

**Features**:
- Daily check-in (mood/energy as lotus petals opening)
- Reflection journal (palm leaf texture)
- Wellness tracker (sacred geometry visualization)
- Meditation/breathing exercises (firefly guides rhythm)

### 2. 🏫 Workspace (Role-Specific Space)
**Essence**: Your active workspace  
**Feeling**: Organized, alive, purposeful  
**Purpose**: Personalized task management, tracking, and collaboration per role:
- **Classroom Workspace** (Teachers): lesson planning, student tracking, class management
- **School Workspace** (Principals/Stewards): administrative visibility, scheduling, community support
- **Learning Studio** (Students): active learning, resources, practice, personal roadmap
- **Family Space** (Guardians): dignified progress visibility, family-school bridge  
**Interaction**: Efficient but warm, like a craftsperson's studio  

**Features**:
- Weekly planner (traditional calendar meets modern grid)
- Lesson templates (illustrated with cultural motifs)
- Workspace notes (quick capture, lotus petal assistant offers suggestions)
- Resources quick-access (batik pattern organization)

### 3. 🌸 Community (Cathedral)
**Essence**: Collective wisdom gathering  
**Feeling**: Temple courtyard, vibrant, human warmth  
**Purpose**: Teacher forums, mentorship, shared stories  
**Interaction**: Social, celebratory, elevated  

**Features**:
- Discussion forums (threaded like liya-vela vines)
- Mentorship matching (intertwining creepers)
- Recognition wall (achievements on stone tablets)
- Collaborative resource sharing (offerings at temple)

### 4. 📚 Library (Studium)
**Essence**: Knowledge repository  
**Feeling**: Ancient manuscript room, living archive  
**Purpose**: Curriculum materials, professional development, teaching wisdom  
**Interaction**: Explorable, discoverable, reverential  

**Features**:
- Searchable resource database
- Curated collections (like museum exhibits)
- Professional learning paths (illustrated journey)
- Cultural teaching materials (Sri Lankan context)

### 5. 👤 Profile (Identity)
**Essence**: Your teacher story  
**Feeling**: Personal shrine, honored biography  
**Purpose**: Achievements, preferences, your teaching philosophy  
**Interaction**: Reflective, proud, evolving  

**Features**:
- Teaching journey timeline (traditional scroll)
- Achievements & badges (lotus mandalas)
- Preferences & settings
- Your shared resources & contributions

## 🪷 The Assistive Presence

### Primary: Lotus Petal
**Character**: Gentle, wise, ever-present guardian  
**Visual**: Single lotus petal that floats, rotates, pulses  
**Behavior**: Appears when needed, fades when not  
**Voice**: Silent but expressive through movement  

**When it appears**:
- Onboarding (guides through first setup)
- Moments of overwhelm (offers breathing exercise)
- Discovery (highlights new features with gentle glow)
- Achievement (dances in celebration)
- Lost/confused (pulses toward helpful action)
- Loading (gentle rotation, never harsh spinning)

**Animation personality**:
- Floats like on water (subtle bobbing)
- Responds to touch (ripple effect)
- Breathes (expands/contracts softly)
- Never rushes (moves with meditation pace)

### Alternative: Firefly (Optional Choice)
**Character**: Curious, playful, illuminating  
**Visual**: Soft glowing orb with gentle trail  
**Behavior**: More active, guides through darkness  
**When to use**: Night mode, or user preference

## 🌿 Design Principles: Aliveness

### 1. Nature Biomimicry

**Not static UI — Living ecosystem**

**Water metaphors**:
- Scrolling feels like flowing water
- Refresh is dew forming on lotus
- Navigation ripples outward from touch
- Content surfaces like islands emerging from mist

**Growth metaphors**:
- Progress bars are vines growing
- Achievements are flowers blooming
- Streaks are roots deepening
- Learning paths are creepers finding light

**Breath metaphors**:
- Cards subtly expand/contract (breathing)
- Lotus assistant pulses like heartbeat
- Transitions have organic easing (inhale/exhale rhythm)
- Background gradients shift like morning sky

### 2. Humanity & Warmth

**Not corporate — Human presence**

**Handmade quality**:
- Slight imperfections (like batik wax variation)
- Hand-drawn icon variants
- Textured backgrounds (woven, painted, carved)
- Font ligatures create natural flow

**Emotional intelligence**:
- App responds to time of day (morning greetings, evening reflection)
- Detects frustration (offers break suggestions)
- Celebrates small wins (not just big achievements)
- Remembers teacher preferences (adapts over time)

### 3. Ethereal & Scenic

**Not flat — Atmospheric depth**

**Light & shadow**:
- Soft ambient occlusion (cards float above surface)
- Glowing edges on focus (oil lamp effect)
- Dappled light through leaves (subtle overlays)
- Golden hour color shifts (morning/evening modes)

**Atmospheric layers**:
- Foreground: Interactive elements
- Midground: Content and cards
- Background: Scenic, meditative (mist, water, temple silhouettes)
- Depth through parallax (gentle, not aggressive)

**Soundscape**:
- Ambient temple sounds (optional, very subtle)
- Natural sounds (water, birds, breeze)
- Traditional instruments (harmonium, bells, drums)
- Silence is also sacred (never over-designed)

### 4. Awe Through Details

**The punctum moments** that make you pause:

- First login: Full lotus bloom with petals falling like snow
- Achievement unlocked: Traditional drums + gold light burst
- Mentor connection: Two fireflies dancing together
- Completed lesson series: Batik pattern completes across screen
- Community milestone: Temple bells chiming in harmony
- Long absence return: Lotus welcoming you back, slightly withered then refreshing
- Deep night work: Fireflies gathering to keep you company

## 📱 Performance: Sacred Constraints

### The Reality: Low-End Phones

**Most Sri Lankan teachers use**:
- 2-4 GB RAM devices
- Older Android versions
- Limited storage (16-32 GB)
- Slower processors
- Intermittent connectivity

**Design implication**: Performance IS the design language

### Optimization Strategy

**1. Lightweight First**
```
Target app size: <20 MB
Image assets: WebP format, progressive loading
Animations: CSS-based, GPU-accelerated only when needed
Code: Tree-shaken, lazy-loaded modules
Fonts: WOFF2, subset to used glyphs only
```

**2. Graceful Degradation**
```
Device tier detection:
- High: Full animations, particle effects, assistive presence
- Mid: Simplified animations, reduced effects
- Low: Essential animations only, static backgrounds

Never sacrifice functionality for beauty on low-end devices
```

**3. Smart Loading**
```
Priority 1: Core navigation and current view
Priority 2: Assistive lotus petal (lightweight SVG)
Priority 3: Background atmosphere and textures
Priority 4: Decorative motifs and enhancements

Progressive enhancement, not progressive punishment
```

**4. Offline Resilience**
```
Core features work offline:
- Self (journal, reflection)
- Classroom (lesson planning with local storage)
- Profile (view/edit)

Sync when connected:
- Community
- Library (cache recently accessed)

Show connectivity status through lotus petal:
- Fully hydrated: Online
- Droplets forming: Syncing
- Dry petals: Offline mode
```

**5. Data Consciousness**
```
Image optimization:
- Low-res thumbnails first
- Full-res on demand only
- Cache aggressively
- Offer "data saver mode" (reduces imagery, keeps functionality)

Video/audio:
- Stream in low quality by default
- Allow download for offline (user choice)
```

## 🎨 Visual Language (Optimized)

### Color Palette

**Primary — Lotus Palette**
- **Nelum Pink** `#F4C2C2`: Fresh lotus petals
- **Mud Brown** `#5D4E37`: Grounding earth
- **Sacred White** `#FFF8F0`: Purity, light
- **Temple Gold** `#D4AF37`: Divine accents

**Secondary — Cultural Palette**
- **Peacock Blue** `#1E88A8`: Water, sky
- **Saffron** `#FF9933`: Wisdom, warmth
- **Palm Green** `#4A6741`: Nature, growth
- **Moonstone Grey** `#C0C0BB`: Temple stone

**Functional**
- **Success**: Palm Green with gold accent
- **Warning**: Saffron
- **Error**: Mud Brown (not harsh red)
- **Info**: Peacock Blue

### Typography (Performance-Optimized)

**Sinhala Script**
- **Display/Headers**: Noto Serif Sinhala (subset, 1-2 weights max)
- **Body**: Noto Sans Sinhala Regular (single weight, comprehensive subset)
- **System fallback**: Default Sinhala fonts

**Latin Script**
- **Pair**: Inter Variable (single file, all weights)
- **System fallback**: -apple-system, Roboto, sans-serif

**Loading strategy**:
```
font-display: swap
Preload critical fonts only
Subset to used character ranges
Cache aggressively
```

### Iconography

**Custom icon set**: Traditional motifs as functional icons

**Approach**:
- SVG sprites (single file, all icons)
- Inline critical icons (Self, Classroom, Community, Library, Profile)
- Lazy-load decorative icons
- Monochrome base, color on accent only

**Icon examples**:
- Self: Lotus in meditation pose
- Classroom: Ola leaf with writing
- Community: Intertwined liya-vela
- Library: Stacked palm manuscripts
- Profile: Circular lotus mandala frame

## 🎭 Interaction Design: Alive, Soothing, Awe

### Navigation Philosophy

**Feel like**: Walking through a temple garden  
**Not**: Clicking through a filing system

**Bottom bar**:
- Smooth, organic transitions
- Active state: Lotus blooms slightly
- Ripple effect from tap point
- Gentle haptic feedback (if device supports)

**Page transitions**:
```
Self → Classroom: Morning mist clearing
Classroom → Community: Doors opening to courtyard
Community → Library: Walking into quiet hall
Library → Profile: Turning to reflection pool
```

**Timing**:
- Transition duration: 300-400ms (meditative, not rushed)
- Easing: Bezier curves mimicking natural motion
- Never instant (jarring), never slow (frustrating)

### Scroll Behavior

**Alive scrolling**:
- Parallax on scenic backgrounds (subtle depth)
- Lotus assistant follows scroll (like floating on water)
- Section headers emerge from mist
- Cards lift as they enter viewport (micro-animation)

**Performance consideration**:
- Disable on low-end devices
- Use transform (GPU) not position (CPU)
- Throttle/debounce scroll events
- Intersection Observer for viewport detection

### Touch Interactions

**Every touch creates life**:

**Tap**: 
- Ripple from touch point (water droplet)
- Gentle scale feedback (pressing into soft surface)
- Color bloom (lotus opening)

**Long press**:
- Context menu emerges like roots breaking surface
- Haptic pulse
- Slight lift shadow

**Swipe**:
- Cards slide like silk cloth
- Reveal actions with batik pattern underneath
- Dismiss like lotus petal falling in stream

**Pull to refresh**:
- Lotus petals open
- Dew forms and drips
- Release: Full bloom, content refreshes

### Loading States

**Never harsh spinners** — Living indicators:

**Global loading** (changing sections):
- Lotus assistant gentle rotation
- Mist fading in/out
- "Breathing" pulse

**Content loading**:
- Skeleton screens with woven texture
- Cards emerging from water (fade + rise)
- Progressive image reveal (blur → sharp)

**Processing/thinking**:
- Lotus petal considering (subtle sway)
- Fireflies gathering (if alternative mode)
- Soft glow pulse

## 🧩 Component Library

### Cards

```
Base card:
- Background: Handloom texture (subtle, optimized)
- Border: 1px with gal-binduwa dots (repeating pattern)
- Corners: 12px radius (rounded like Sinhala letters)
- Shadow: Soft, warm (like paper on temple stone)
- Hover/Active: Slight lift (4px → 8px elevation)

Performance:
- Use box-shadow sparingly
- Prefer border for low-end devices
- Texture as CSS pattern, not image where possible
```

### Buttons

```
Primary (Call to action):
- Background: Temple Gold gradient
- Text: Mud Brown
- Icon: Lotus motif or cultural symbol
- State—Rest: Subtle glow
- State—Hover: Glow intensifies (oil lamp)
- State—Active: Pressed into surface
- State—Disabled: Desaturated, reduced opacity

Secondary:
- Background: Transparent
- Border: Sacred White/Peacock Blue
- Ripple on tap

Performance:
- Gradients only on primary actions
- Solid colors on secondary
- Avoid multiple box-shadows
```

### Input Fields

```
Text input:
- Background: Sacred White with palm leaf texture
- Border: Peacock Blue (focus: Temple Gold)
- Border animation: Liya-vela vine grows on focus
- Placeholder: Subtle Sinhala/English
- Label: Floats up on focus (lotus rising)

Validation:
- Success: Palm Green accent + lotus icon
- Error: Mud Brown accent + gentle shake
- Helper text: Below field, not overlay

Performance:
- Texture as background-image (optimized SVG)
- Border animation CSS-only
- Avoid heavy blur/filter effects
```

### Lists

```
List items:
- Divider: Diyarella wave pattern (subtle)
- Icon area: Cultural motif relevant to content
- Swipe actions: Batik pattern reveals underneath
- Long press: Contextual menu emerges

Performance:
- Virtual scrolling for long lists
- Recycle DOM elements
- Lazy load images as needed
- Intersection Observer for appearing items
```

## 🎵 Sound Design (Performance-Conscious)

### Audio Philosophy

**Use sparingly** — Silence is sacred  
**Make meaningful** — Every sound carries culture  
**Keep lightweight** — Small file sizes, strategic loading

### Sound Library

**Notification tiers**:
- **Critical**: Temple bell (200ms, 8kHz sample)
- **Important**: Harmonium note (150ms)
- **Casual**: Soft wood tap (100ms)

**Interaction sounds**:
- **Success**: Ascending harmonium chord
- **Error**: Descending wood block
- **Achievement**: Drum flourish (geta bera)
- **Navigation**: Soft cymbal wash

**Ambient (optional, user controlled)**:
- **Self**: Temple ambience (very subtle, looping)
- **Classroom**: Soft rainfall (optional focus mode)
- **Community**: Distant chatter, birds
- **Library**: Page turning, gentle breathing
- **Profile**: Silence (reflection)

**File strategy**:
```
Format: MP3 (wide compatibility) or AAC
Size: <5KB per sound effect
Ambient: <100KB per loop
Loading: Lazy load, cache aggressively
User control: Global mute, per-category control
Accessibility: Visual alternatives for all sounds
```

## ⚡ Technical Implementation

### Architecture

```
Frontend: React Native / Flutter
- Cross-platform (Android priority, iOS secondary)
- Native performance
- Shared codebase with platform-specific optimizations

State Management: Lightweight (Zustand/Jotai)
- Minimal bundle size
- Simple, predictable
- Easy offline support

Animations: 
- React Native Reanimated / Flutter Animations
- GPU-accelerated
- Interruptible
- Device-tier responsive

Offline-First:
- Local-first architecture
- SQLite for structured data
- File system for media
- Background sync when connected

Backend:
- GraphQL (efficient data fetching)
- CDN for static assets (regionally distributed)
- Edge functions for lightweight operations
```

### Performance Budget

```
App bundle size:
- Android APK: <20MB
- iOS IPA: <25MB

Launch time:
- Cold start: <3s on low-end device
- Warm start: <1s

Time to interactive:
- First view: <2s
- Subsequent views: <500ms

Memory footprint:
- Idle: <100MB
- Active use: <200MB
- Peak: <300MB

FPS targets:
- Scrolling: 60fps
- Animations: 60fps
- Lotus assistant: 30fps (acceptable on low-end)

Network:
- Initial load: <500KB
- Per-screen data: <50KB
- Images: Progressive, lazy
```

### Device Tier Detection

```javascript
// Example logic
function detectDeviceTier() {
  const ram = getDeviceRAM();
  const cores = getCPUCores();
  const year = getDeviceYear();
  
  if (ram >= 4 && cores >= 6 && year >= 2020) {
    return 'high'; // Full experience
  } else if (ram >= 2 && cores >= 4) {
    return 'mid'; // Reduced effects
  } else {
    return 'low'; // Essential only
  }
}

// Adapt features accordingly
const config = {
  high: {
    lotusPetal: true,
    particleEffects: true,
    parallax: true,
    complexAnimations: true,
    backgroundTextures: 'full'
  },
  mid: {
    lotusPetal: true,
    particleEffects: false,
    parallax: false,
    complexAnimations: 'simplified',
    backgroundTextures: 'reduced'
  },
  low: {
    lotusPetal: 'static', // No animation
    particleEffects: false,
    parallax: false,
    complexAnimations: false,
    backgroundTextures: 'minimal'
  }
};
```
