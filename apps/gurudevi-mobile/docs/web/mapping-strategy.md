# Gurudevi Library: Mapping Strategy (Social Topology)

The Map in Gurudevi is not just a UI; it is the **Spatial Epistemology** of the project. We are mapping the invisible connections between knowledge, institutions, and people.

## 1. Versatile Topologies
The Map is a single entry point into two different "Worlds" of data:

### A. The Geographic World (Real-Earth)
Mapping entities with physical presence using **GPS (Lat/Lng)**.
- **Layers**: Schools, Educational Charities, EdTech Offices, Researchers.
- **Visual**: Real world map (Sri Lanka/Global).

### B. The Abstract Cosmos (Islands of Knowledge)
Mapping concepts and pathways using **Cartesian (X/Y)** space.
- **Layers**: Mind Maps, Knowledge Islands (Kinnu-style clusters), Learning Pathways.
- **Visual**: A starry cosmos or "Islands" connected by resonance links.

## 2. Technical Implementation
- **Schema**: Resources or nodes have `lat/lng` for Geographic and `map_x/map_y` for Abstract.
- **Layer Switching**: A primary toggle switches the projection from Earth to Cosmos.

## 3. Data Sources
- **Official MoE Data**: For the Sri Lanka School layer.
- **AI Discovery**: To surface new "Charity" and "Tech" nodes globally.
- **Community Input**: Users suggesting new layers (e.g., "History Sites").
