# Database Drift Scorecard

This report is generated by [`scripts/check-database-drift.mjs`](/C:/Users/Naween/projects/polymath-platform/scripts/check-database-drift.mjs).

## Reading Guide

- Structural checks are high confidence.
- Policy checks are high confidence when based on RLS presence or absence.
- Semantics still require human review.
- Ignore rules are governance decisions, not automatic truth.

## What to trust first

1. Live DB snapshot JSON.
2. Drift summary JSON.
3. Markdown report.
4. Ignore manifest.

## What not to trust blindly

- A single score.
- A generated “perfect sync” message.
- Any mismatch that has not been categorized as intentional or accidental.

## Required Review Questions

- Is this a structural drift?
- Is this an intentional legacy divergence?
- Is this a read-model projection?
- Is this a trigger-owned field?
- Is this a true access-control mismatch?
- Does the same rule exist in ZenStack and RLS by design?
