# Gurudevi Library: Planned Resource Types

To ensure a diverse and meaningful "epistemic universe," the following resource types are prioritized for ingestion and display.

| Type | Description | Primary Sources |
| :--- | :--- | :--- |
| **Book** | Digital books, textbooks, or classic literature in PDF/EPUB. | Internet Archive, Project Gutenberg, MoE. |
| **Video** | Curated educational videos or internal training content. | YouTube, Vimeo, Internal Uploads. |
| **Documentary** | High-production, deep-dive films on social/educational topics. | YouTube, Film Archives. |
| **Article** | Long-form essays, news reports, or pedagogical blog posts. | NewsAPI, Medium, Educational Blogs. |
| **Research** | Academic papers, studies on psychology, and pedagogy. | arXiv, ResearchGate (Open Access), Universities. |
| **Guide** | Handbooks, official circulars, and DIY instructional material. | Ministry of Education, NGO toolkits. |
| **Map** | Interactive or static knowledge maps and infographics. | Internal creation, Visual Repositories. |

## Taxonomy Strategy
Each item is tagged with:
1. **Target Role**: Teacher, Student, Principal, or All.
2. **Subject**: Pedagogy, Science, Philosophy, Arts, etc.
3. **Grade Level**: Early Childhood, Primary, Secondary, Tertiary.
4. **Language**: Sinhala (si), Tamil (ta), English (en).
