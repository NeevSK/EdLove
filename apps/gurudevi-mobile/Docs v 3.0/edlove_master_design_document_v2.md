## I. FOUNDATIONAL VISION

### Core Mandate
Edlove.org is a **Digital Sanctuary** serving as the definitive reference point for reimagining education. It bridges ideology (what could be) and realism (what is), operating simultaneously as:
- **Universal portal** for global paradigm consciousness
- **National intervention** for Sri Lankan educational transformation

### Sacred Commitments
1. **Accessibility**: Free and open to all, forever
2. **Beauty**: Cinematic quality, never sacrificing aesthetics for expedience
3. **Wholeness**: All six domains visible from launch (varying depths)
4. **Flexibility**: Built for evolution, not rigidity
5. **Love**: Every decision filtered through "Does this serve human flourishing?"

### Aesthetic Constitution
- **Atmosphere**: Ethereal, organic, tactile (Tree of Life, Upstream Color)
- **Structure**: Precision, modernism, framing (Columbus)
- **Tone**: Intimate, sensory, textural (Duke of Burgundy, Taste of Things)
- **Navigation**: Quiet, respectful, never overwhelming
- **Pacing**: Contemplative, varied scroll speeds (Malick effect)

## III. TECHNICAL ARCHITECTURE

### Stack Selection Principles
1. **AI-Friendly**: Can be built/modified via Cursor, Claude, other AI tools
2. **Free/Low-Cost**: Sustainable for unfunded project
3. **Performant**: Fast load times, accessible globally
4. **Maintainable**: Simple enough for solo developer with AI support
5. **Flexible**: Easy to modify as vision evolves

### Chosen Technology

**Frontend Framework**: 
- **Astro** (static site generator, component-agnostic)
  - Why: Excellent performance, works with any UI framework, AI-friendly syntax
  - Allows mixing: Svelte for interactive pieces, React if needed, vanilla JS where simple

**Styling**:
- **Tailwind CSS** (utility-first)
  - Why: Rapid development, consistent design system, AI can generate it well
- **Custom CSS** for cinematic effects (GSAP, Framer Motion)

**Animations**:
- **GSAP** (GreenSock) for scrollytelling
- **Framer Motion** for micro-interactions
- **Three.js** (future) for 3D cosmos

**Content Management**:
- **Markdown + Frontmatter** for all text content
- Stored in Git (version controlled, transparent)
- Easy for AI to generate and modify

**Search**:
- **Pagefind** (free, static search) initially
- **Algolia** (paid) if/when traffic justifies

**Hosting**:
- **Cloudflare Pages** (free tier)
  - Unlimited bandwidth, global CDN, automatic SSL
  - Edge functions for dynamic features

**Analytics**:
- **Plausible** or **Fathom** (privacy-friendly, ~$9/month)
- Or **Cloudflare Analytics** (free, basic)

**Domain**:
- edlove.org (~$15/year)
- Optional subdomains: app.edlove.org, community.edlove.org

**Total Monthly Cost**: $0-15 (fully sustainable even unfunded)

## V. CONTENT STRATEGY

### Voice & Tone Guidelines

**Core Principles**:
- **Tender but truthful**: Don't sugarcoat systemic problems, but approach with compassion
- **Poetic but practical**: Beautiful language that still conveys actionable information
- **Inclusive**: Accessible to teachers, students, parents, policymakers
- **Non-jargon**: Explain complex ideas simply without dumbing down

**Examples**:

❌ **Academic**: "The hegemonic discourse of standardized assessment perpetuates epistemic violence"

✅ **Edlove**: "When we measure all children by the same test, we tell most of them they're failing. What if learning isn't meant to be standardized?"

❌ **Corporate**: "Our platform leverages AI to optimize educational outcomes"

✅ **Edlove**: "We've created a tool to support teachers in seeing each student fully"

❌ **Preachy**: "Traditional schools are destroying our children's souls!"

✅ **Edlove**: "Many of us carry wounds from school. What if we could create learning spaces that heal instead of harm?"

### Content Templates

**Thinker Profile Structure**:
1. Opening quote (their most powerful idea)
2. Context (who they were, when they lived, what they faced)
3. Core Philosophy (3-4 key concepts)
4. Revolutionary Insight (what made them different)
5. Legacy & Application (how their ideas live today)
6. Resources (books, videos, further reading)
7. Reflection Questions (for the reader)

**Paradigm Deep-Dive Structure**:
1. Essence (one-paragraph capturing the core)
2. Origin Story (how/why it emerged)
3. Key Principles (the philosophical foundation)
4. In Practice (what it actually looks like in a learning space)
5. Strengths & Challenges (honest assessment)
6. Real Examples (schools/projects using this approach)
7. How to Explore Further (resources, communities)
