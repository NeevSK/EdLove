# Gurudevi: Sacred Technology for Sri Lankan Teachers

## 🪷 Project Overview

### Vision
**Gurudevi** (ගුරු දෙවි) is a mobile application designed as a sanctuary for Sri Lankan educators - a technology that restores energy rather than extracting it.

### Core Philosophy: The Lotus Metaphor
- **Rooted in mud**: Acknowledging harsh educational conditions
- **Rising through water**: Journey of resilience and growth
- **Hydrophobic surface**: Protecting teacher's dignity
- **Blooming above**: Achieving profound educational purpose

## 🏛️ Architectural Foundations

### Product Identity
- **Not**: Another Learning Management System
- **Is**: An education ecology support system
- **Unique Positioning**: LMS + Sanctuary + Sri Lankan Context + Mobile-First + Wellbeing

### 5-Tab Sacred Structure
1. 🧘 **Self** (Personal Sanctuary)
2. 🏫 **Classroom** (Active Teaching Space)
3. 🌸 **Community** (Collective Wisdom)
4. 📚 **Library** (Knowledge Repository)
5. 👤 **Profile** (Professional Journey)

## 🔧 Technical Architecture

### Technology Stack
- **Framework**: Expo React Native
- **State Management**: Zustand
- **Database**: Supabase, WatermelonDB
- **Localization**: Sinhala/Tamil first
- **Performance**: Optimized for low-end devices

### Key Technical Principles
- Offline-first
- Local data sovereignty
- Minimal bundle size
- Graceful degradation
- Cultural authenticity

## 🎨 Design DNA

### Design Laws
1. **Local Sovereignty**: Device is the universe
2. **Procedural Beauty**: Generated, not imported
3. **Digital Animism**: Technology as a living companion

### Aesthetic Approach
- Sanctuary color palette
- Organic, breath-like animations
- Cultural motifs (lotus, batik, temple references)
- Punctum moments of unexpected beauty

## 💡 Product Strategy

### Market Position
- **Free Tier**: Basic features
- **Pro Tier**: LKR 1,500/month
- **Premium Tier**: LKR 3,000/month

### Success Metrics
**Quantitative**:
- App launch time < 3s
- 60fps scrolling
- App size < 20MB
- High retention rates

**Qualitative**:
- Teachers feel "seen"
- Reduces stress
- Culturally resonant
- Serves teaching, not just tracking

## 🚀 Development Roadmap

### Phase 1 (2 months)
- Core architecture
- 5-section navigation
- Offline data management
- Basic features for Self/Classroom

### Phase 2 (6-12 months)
- Advanced community features
- AI-assisted mentorship
- Deeper cultural integrations
- Performance optimizations

## 🌟 Ethical Commitment

> Every design decision must return more energy than it consumes.

Gurudevi is not just software - it's a living shrine to the teaching profession, honoring 2000 years of cultural wisdom.
