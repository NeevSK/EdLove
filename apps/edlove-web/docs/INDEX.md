# Edlove Web Documentation Index

This index acts as a reference for the design documents, philosophy, technical architectures, subdomains, and strategic roadmaps for the Edlove web application.

## Directory Structure

- **`Core/`** — Master design documents, design philosophies, and core specifications
- **`architecture/`** — Technical specs and subdomain mapping notes
- **`current_progress/`** — Active roadmaps and strategic plans
- **`domain-1/`** to **`domain-6/`** — Deep-dive studies and domain-specific papers (e.g. shadow education, government schooling, education genealogy)
- **`ed-tech-and-world/`** — Research on global innovation galleries, teacher lifecycles, and pattern languages
