## WHY SUBDOMAINS (TEMPORARILY)

**Economic reality:**
- Separate `.lk` domains cost $15-30/year each
- Current priority: build EdLove.org first (the main house)
- Subdomains are free, professional, and functional

**Strategic benefits:**
- Shows ecosystem connection (all under edlove.org umbrella)
- Easy to deploy independently (separate Astro projects)
- Easy to migrate later (301 redirects preserve SEO)
- Professional enough for current needs

**Migration path:**
- When Intuitui generates revenue → buy intuituilabs.lk
- When Gurudevi has funding → buy gurudevi.lk
- Keep redirects forever (SEO, bookmarks, links)
