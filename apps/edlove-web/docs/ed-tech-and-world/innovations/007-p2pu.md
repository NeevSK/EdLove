## 1. Executive Summary & Core Philosophy

**Peer 2 Peer University (P2PU)** is a global open-source educational movement and grassroots non-profit that pioneered **Learning Circles**—lightweight, facilitated, in-person study groups for people who want to complete online courses together in public libraries, community centers, and shared public spaces for free.

P2PU identified the fundamental bottleneck of digital learning: open online educational resources (OER) are abundant, but human motivation, social accountability, and self-efficacy are scarce when learners sit alone behind screens. P2PU solved this not by hiring expensive professors, but by **democratizing facilitation**:
- **Peer Facilitation over Sage-on-Stage**: Anyone (a librarian, a community elder, a fellow student) can facilitate a Learning Circle without being a subject-matter expert. The facilitator manages the time, fosters psychological safety, and keeps the group aligned, while the group collaboratively interrogates the OER course materials.
- **Public Library Anchoring**: Treats public libraries as sacred civic learning sanctuaries, completely free from commercial tuition extraction.

## 2. Architectural & Technical Foundation

```
┌────────────────────────────────────────────────────────────────────────┐
│ P2PU LEARNING CIRCLES TECHNICAL ARCHITECTURE                           │
├────────────────────────────────────────────────────────────────────────┤
│ • Web Application: Python / Django Web Framework                       │
│ • Frontend Interface: Vanilla JavaScript + Bootstrap / Modern CSS      │
│ • Database: PostgreSQL (Relational schema for teams, circles, surveys) │
│ • Notification Engine: Celery + Redis + Twilio SMS & SendGrid Email    │
│ • API & Integrations: Discourse Community Forum (community.p2pu.org)   │
│ • License: BSD 3-Clause (100% Free & Open Source)                      │
└────────────────────────────────────────────────────────────────────────┘
```

1. **The Learning Circle Facilitator Toolkit**:
   - Web application (`learning-circles`) providing an end-to-end dashboard: creating 6-to-8 week course schedules, automated SMS/email reminders, attendee registration management, and weekly feedback surveys.
   - Built to require zero technical maintenance from non-technical public librarians.

2. **Course Commons Curation Engine**:
   - A community-vetted directory linking high-quality OER courses (Khan Academy, MIT OpenCourseWare, Coursera free tiers, OpenLearn) to structured, downloadable PDF facilitator session guides.

3. **Radical Data Dignity & Low Bandwidth**:
   - Zero tracking cookies, zero ad pixels. The web interface is engineered to load rapidly over constrained public Wi-Fi connections.

## 3. Comparative Matrix: Traditional University Extension vs. P2PU Learning Circles

| Dimension | Continuing Ed / University Extension | P2PU Learning Circles |
| :--- | :--- | :--- |
| **Cost to Student** | $300 – $1,500 per course | **100% Free (Public Commons)** |
| **Instructor Dynamic** | Paid lecturer / Top-down authority | **Peer Facilitator / Co-learner ("Guide on the Side")** |
| **Physical Venue** | Paywalled campus lecture halls | **Civic Public Libraries, Parks, Community Hubs** |
| **Software Stack** | Heavy enterprise LMS (Blackboard/Canvas) | **Lightweight Open-Source Django Platform + SMS** |

## 4. Synthesis & Key Lessons for EdLove & Gurudevi (Sri Lanka)

### Strengths to Emulate:
1. **Separation of Facilitation from Subject Expertise**: Unlocks millions of potential study groups because facilitators don't need master's degrees in the subject to organize a supportive cohort.
2. **Civic Space Reclamation**: Re-activates under-utilized community libraries as vibrant centers of digital upskilling.

### Limitations:
1. **Drop-out in the Absence of Facilitator Passion**: The success of any learning circle is heavily tied to the facilitator’s emotional warmth and consistency.

### ✦ Direct Grounding for Sri Lankan Local Libraries (*Pusthakala*):
- Sri Lanka possesses an extensive network of municipal and provincial public libraries (*Praja Mandalaya* / *Pusthakala*) that are under-digitized and under-utilized.
- EdLove can deploy P2PU's open-source Learning Circle architecture across Sri Lankan rural libraries: pairing local youth with free OER materials and local peer facilitators for O/L mathematics, IT literacy, and language studies without tuition burdens.
