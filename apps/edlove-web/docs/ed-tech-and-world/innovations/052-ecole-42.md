# Innovation Dossier: École 42 (42 Network — Teacherless Peer-to-Peer Heutagogy & The Piscine)

> **Category**: 5. Radical Peer-to-Peer & Heutagogy  
> **Origin / Custodian**: France & Global / Founded by Xavier Niel, Nicolas Sadirac, Kwame Yamgnane, Florian Bucher (Paris, 2013)  
> **Official Network Portal**: [42.fr](https://www.42.fr) / [42network.org](https://www.42network.org)  
> **Global Scale**: 54+ autonomous campuses across 31 countries (Over 21,000 active students)  
> **Core Model**: 100% Free Tuition, Zero Teachers, Zero Classrooms, Zero Academic Prerequisites  
> **License**: Non-Profit Educational Endowment / Open Network Federation

---

## 1. Executive Summary & Core Philosophy

**École 42 (The 42 Network)** is the world’s most radical and successful experiment in **teacherless, peer-to-peer, self-directed software engineering education (Heutagogy)**, fundamentally disproving the assumption that higher technical education requires high-paid professors, lecture amphitheaters, or expensive tuition fees.

Traditional computer science university programs are burdened by obsolete academic lectures, hyper-competitive grading, and exorbitant tuition debts ($30,000–$100,000) that exclude underprivileged youths. 42 dismantled this entire infrastructure:
- **Zero Teachers, Zero Lectures, Zero Books**: There are no professors delivering lectures. All learning happens through hands-on project problem-solving, collaborative inquiry, and searching the open web.
- **The "Piscine" (The Swimming Pool Selection)**: An intense 4-week trial where thousands of applicants from all walks of life (high-school dropouts, artists, former delivery drivers) are dropped into complex C-programming challenges with no instructions, discovering how to collaborate and survive together.
- **Peer-to-Peer Evaluation Economy**: Students cannot advance simply by passing automated tests; they must have their code personally audited line-by-line by 3 random peers, defending their architectural decisions verbally.

## 2. Architectural & Technical Foundation

```
┌────────────────────────────────────────────────────────────────────────┐
│ ÉCOLE 42 INTRANET & EVALUATION TOPOLOGY                                │
├────────────────────────────────────────────────────────────────────────┤
│ • Gamified Skill Tree: Galaxy Graph (`Holy Graph`) of ~100 C/C++ Nodes │
│ • Automated Test Engine: *Moulinette* (Sub-second headless code test)  │
│ • Peer Economy: Evaluation Points (`Correction Points` ledger)         │
│ • Physical Hardware: 24/7 Open Unix Workstations (Mac/Linux cluster)   │
│ • Intranet Portal: Custom Ruby on Rails / React LMS (`profile.intra.42.fr`)│
│ • Anti-Cheating: Multi-peer cross-audit & random oral code defenses    │
└────────────────────────────────────────────────────────────────────────┘
```

1. **The Correction Point Micro-Economy**:
   - To submit a completed project for grading, a student must spend **Evaluation Points**.
   - To earn Evaluation Points, the student must volunteer to evaluate and critique other students' code submissions. This creates an unshakeable, self-sustaining circular economy where helping others is the mathematical prerequisite for personal progress.

2. **The *Holy Graph* (RPG-Style Curricular Map)**:
   - The curriculum is modeled as an interactive constellation graph. Mastering low-level Unix memory allocation (`ft_printf`, `get_next_line`) unlocks branching paths into 3D graphics (Raytracing with miniLibX), kernel development, algorithms, networking, and security.

3. **The *Moulinette* Dual-Pass Verification**:
   - The automated test engine (*Moulinette*) compiles code with strict compiler flags (`-Wall -Wextra -Werror`), testing edge cases, memory leaks (`valgrind`), and style norms (*Norminette*).
   - If *Moulinette* passes, the student must then pass 3 in-person peer evaluations to receive full credit.

## 4. Synthesis & Key Lessons for EdLove & Gurudevi (Sri Lanka)

### Strengths to Emulate:
1. **The Correction Point Covenant**: Turning evaluation into a reciprocal peer currency operationalizes Seneca’s *Docendo Discimus* at massive institutional scale.
2. **True Meritocratic Accessibility**: Eradicates credentialist gatekeeping, discovering world-class engineering talent among self-taught and marginalized youths.

### Limitations:
1. **Intense Psychological Stress**: The unstructured, self-directed "Piscine" can trigger severe impostor syndrome and anxiety for students accustomed to traditional spoon-fed guidance.

### ✦ Direct Grounding for Sri Lanka's Youth & Tech Divide:
- In Sri Lanka, government university state intake is capped at ~35,000 seats, leaving over 100,000 qualified A/L students stranded each year without affordable higher education options.
- EdLove can adapt 42’s **open peer-evaluation mechanics and project graph into Sri Lankan community learning pods**: enabling young Sri Lankans to master software craftsmanship, web engineering, and AI literacy collaboratively through peer review without paying millions of rupees to private degree mills.
