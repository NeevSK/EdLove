# Gurudevi Public Site (Marketing)

**URL**: `gurudevi.edlove.org` (eventually `gurudevi.lk`)

This app is the public-facing landing/marketing site for the Gurudevi project (About, FAQ, Privacy, etc.).

## What Gurudevi is

Gurudevi is an "Education Ecology Support System" built around five pillars:

- SELF
- CLASSROOM
- LIBRARY
- COMMUNITY
- PROFILE

## Tech stack

- Framework: Astro
- Styling: Tailwind CSS
