# PROJECT CONTEXT: gurudevi-marketingWeb

## IDENTITY
**Name**: Gurudevi (Public Site)  
**URL**: `gurudevi.edlove.org` (eventually `gurudevi.lk`)  
**Role**: Public landing / marketing / information site for the Gurudevi project

## CORE CONCEPT
Gurudevi is an "Education Ecology Support System".
It is more than an LMS; it is a sanctuary for teachers and anyone else too.

- **Philosophy**: "Teaning" (mending/supporting the teaching-learning impedance match).
- **Five Pillars**: SELF, CLASSROOM, LIBRARY, COMMUNITY, PROFILE.

## AESTHETICS & DESIGN
**Theme**: Sanctuary / Lotus

- **Colors**: Teal, Gold, White.
- **Vibe**: Breathing, calm, meditative, safe.
- **Key Element**: The Lotus (blooming, breathing animations).
- **Relation to EdLove**: Uses the EdLove foundation but applies a specific "Sanctuary" context.

## TECH STACK
- **Framework**: Astro
- **Styling**: Tailwind CSS (presumed, check config)
