# Gurudevi Web Companion

**URL**: `gurudevi.edlove.org` (eventually `gurudevi.lk`)

## 🆔 Identity
**Gurudevi** is an "Education Ecology Support System". It serves as a sanctuary for teachers and a companion to the mobile app, embracing the philosophy of "Teaning" (mending/supporting the teaching-learning impedance match).

## 🧠 Core Concept
Gurudevi goes beyond traditional LMS functions. It is a support system built on five pillars:
- **SELF**
- **CLASSROOM**
- **LIBRARY**
- **COMMUNITY**
- **PROFILE**

## 🎨 Aesthetics
- **Theme**: Sanctuary / Lotus
- **Colors**: Teal, Gold, White
- **Vibe**: Breathing, calm, meditative, safe

## 🛠️ Tech Stack
- **Framework**: Astro
- **Styling**: Tailwind CSS
