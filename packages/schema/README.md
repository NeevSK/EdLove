# @repo/schema

The canonical data schemas and entity definitions for the **Gurudevi** platform and **EdLove** ecosystem.

---

## Purpose

Acts as the single source of truth for database models, validation rules, and schema migrations across mobile and web environments.

---

## What It Owns

* **ZenStack Schema (`schema.zmodel`)**: Multi-tenant authorization rules, data relationships, and access policies.
* **TypeScript Types**: Generated models and input types for type-safe application logic.
* **Migrations**: Database migration scripts tracking schema evolution.
