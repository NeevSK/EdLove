# @repo/database

The database client and local storage layer for the **Gurudevi** platform and **EdLove** ecosystem.

---

## Humane Vision & Purpose

This package provides reliable, offline-first data synchronization so that learning records, student reflections, and classroom activities are safely preserved even with unstable connectivity.

---

## What It Owns

* **Local Sync Adapters**: PowerSync integration for bidirectional offline sync.
* **Database Clients**: Drizzle ORM query bindings for Postgres and local SQLite.
* **Migration Runners**: Utilities to apply and verify data migrations safely.
